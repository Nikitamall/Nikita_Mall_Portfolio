# Nikita Mall — Interactive Portfolio

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive styling, animations and dark/light theme
- `script.js` — typing effect, scroll reveal, project filters, project modal, theme toggle, mobile menu and contact form
- `profile.jpg` — uploaded profile photo

## Run locally
1. Keep all files in the same folder.
2. Open `index.html` in Chrome/Edge, or use VS Code Live Server.
3. Replace/update any social links or phone number if needed.

## Important
The contact form opens the visitor's email client using `mailto:`. It does not send messages through a backend.
